## 📖 项目简介

在以**豆包、Kimi、Perplexity、DeepSeek、ChatGPT** 为代表的大模型时代，传统基于关键词密度和外链堆砌的 SEO（搜索引擎优化）正在全面失效。大模型的实时推荐与联网搜索本质上由 **RAG（检索增强生成）与知识图谱实体对齐（Entity Linking & Grounding）** 驱动。

**启灵GEO** 是国内领先的真正工业级 WordPress GEO 插件。它通过在站内构建结构化知识图谱、自动生成 `llms.txt`、输出高可信度事实证据链，并结合前台 AI 爬虫雷达与全网外部引证包，帮助品牌构筑**“独立站（核心知识源）+ 全网公域（环形引证）”**的立体召回矩阵，彻底占领大模型推荐心智。

## 🚀 核心功能特性

### 1. 🌐 AI 专属基础设施与知识图谱 (`llms.txt` & Schema)
* **动态 `/llms.txt` 与 `/llms-full.txt` 协议**：
  * 遵循国际 **llmstxt.org** 全球标准，为各大 AI 爬虫提供零噪音、纯文本 Markdown 站点核心知识库；
  * 内置**双重路由保障**，支持子目录与根目录自适应，无需手动刷新固定链接即可生效；
  * 自动在全站 `<head>` 注入发现标签，并在 `robots.txt` 中写入抓取授权指引；
  * 配备 12 小时智能 Transient 缓存，文章或品牌资料更新时毫秒级自动刷新。
* **全局 `Organization` + `sameAs` 实体网络 Schema**：
  * 在全站前台注入符合 Schema.org 规范的机构实体 JSON-LD；
  * 支持配置知乎机构号、官方微博、微信公众号、百度百科等全网权威链接，强行建立 AI 实体绑定。
* **文章级 `FAQPage` 结构化数据**：
  * 自动抽取正文 FAQ 问答，以标准 JSON-LD 注入页面头部，供 ByteSpider 等爬虫直接提取为精选回答。

### 2. 🕷️ AI 爬虫探测雷达 (AI Crawler Radar)
* **毫秒级零负担嗅探**：
  * 挂载于请求路由阶段，**99.9% 的普通人类访客完全零数据库写入**，秒级放行；
  * 仅对命中的 AI 搜索爬虫（字节跳动 `Bytespider`、OpenAI `GPTBot`/`OAI-SearchBot`、Anthropic `ClaudeBot`、Perplexity `PerplexityBot`、Google `Google-Extended`、Apple 智能等）进行轻量捕获。
* **可视化雷达看板（【启灵GEO】 $\rightarrow$ 【爬虫雷达】）**：
  * 📊 **指标卡片**：今日 AI 抓取次数、近 7/30 天抓取次数、累计捕获条数、最活跃爬虫；
  * 🤖 **爬虫排行**：按品牌色彩（豆包蓝、OpenAI 绿、Claude 橙、Perplexity 青）展示抓取频次与占比进度条；
  * 📑 **热门被爬页面 TOP 5**：实时计算最受 AI 关注的文章路径与标题；
  * 📋 **实时流水表**：抓取时间、爬虫徽章、请求 URL、HTTP 状态码、IP 与完整 User-Agent 折叠展开。
* **🛡️ 双重防数据库膨胀熔断器**：
  * **第一道**：默认 30 天自动轮转异步清理过期日志（可设 7~180 天）；
  * **第二道（硬顶熔断）**：单表强制设定 **10,000 条物理上限**，超出自动对半修剪，表体积**恒定在 3MB 以内**，彻底免除数据库暴增隐患。

### 3. 📦 全网外部信源 GEO 引证分发包 (Off-page Repurposing)
* 破解 AI 搜索“孤证不立”定律，在文章编辑后台一键生成 3 套公域高权重引证稿件：
  * **🔷 知乎深度答主版**：以专业行业答主口吻展开科普分析，自然植入本品牌实体与可信论据，带一键复制；
  * **📕 小红书爆款图文版**：生成 3 个不同情绪维度的吸睛爆款标题、口语化正文、Emoji 痛点排版与话题标签，带一键复制；
  * **📰 行业快讯通稿版**：客观第三人称新闻通稿，适合百度百家号、今日头条新闻源收录，带一键复制。
* 生成结果持久化保存在文章 Meta 中，刷新不丢失，发文后几秒即可完成全网引证铺设。

### 4. 🧠 工业级中枢架构与内容资产
* **品牌实体库 (Brand Entity Library)**：建立品牌名称、核心产品、推荐场景、排除场景、权威证明与别名矩阵；
* **事实证据与论据库 (Evidence Library)**：遵循普林斯顿 GEO 论文标准，强化内容事实密度与可验证引据；
* **异步任务队列 (Queue Worker)**：支持后台批量排队分析，支持 WP-Cron、异步 AJAX 调度与外部 REST 触发；
* **多模型与多渠道映射**：无缝对接 OpenAI、DeepSeek、字节豆包等大语言模型，支持连接测试与重试机制。

### 5. 🛡️ 主动安全防御基线
* **针对 PHP2Shell（CVE-2026-109618 / CVE-2026-109619 CVSS 9.2+ RCE 漏洞）**：
  * 严格锁定 PHP 安全补丁基线（PHP 8.2 >= 8.2.35，8.3 >= 8.3.36，8.4 >= 8.4.27），坚决拒绝带病运行；
* **WordPress Coding Standards (WPCS) 高度合规**：
  * 全插件 56 处精细化 `current_user_can()` 权限校验，封死越权漏洞；
  * 全流程使用 `check_admin_referer()` 与 `check_ajax_referer()` 实施 CSRF 严密防护；
  * 数据库批量操作全部采用标准参数化占位符（`%d` 动态绑定），杜绝 SQL 拼接；
  * 严格限制 Option Autoload，插件庞大数据绝不占用前台内存池。

## 🛠️ 安装与使用环境要求

* **WordPress 版本**：5.8 或更高版本
* **PHP 版本**：8.2.35+（强制要求满足核心安全补丁基线）
* **MySQL 版本**：5.7+ 或 MariaDB 10.3+
* **配套主题**：深度适配启灵主题生态；提供前台标准样式注入与自适应降级。

### 快速安装：
1. 下载本仓库源码包，解压后重命名为 `qilinggeo`；
2. 上传至 WordPress 站点的 `/wp-content/plugins/` 目录；
3. 进入 WordPress 后台 **【插件】** 列表，找到 **启灵GEO** 并点击启用；
4. 进入后台 **【启灵GEO】 $\rightarrow$ 【基础设置】**，填入您的 AI 模型 API Key 并保存；
5. 进入 **【全局品牌资料】** 填写您的品牌定位、核心业务与 `sameAs` 社交主页链接即可开启全域 GEO。

## 📝 发文三阶段标准工作流

```mermaid
flowchart LR
    A["阶段一：正文诊断"] --> B["修改并保存文章"]
    B --> C["阶段二：生成站内 FAQ/Schema"]
    C --> D["阶段三：一键生成全网引证包"]
    D --> E["分发至知乎/小红书/百家号"]
    E --> F["AI 爬虫双向召回与推荐"]
```

1. **第一阶段：AI 深度诊断与优化建议**
   * 编辑器下方点击“开始 GEO 分析”，AI 自动诊断当前正文的缺口与改写建议；
2. **第二阶段：生成站内 FAQ 与核心摘要**
   * 编辑器下方点击“生成 FAQ/摘要”，自动填充文章摘要、核心要点与 `FAQPage` 结构化数据并保存；
3. **第三阶段：生成全网 GEO 引证分发包**
   * 编辑器下方点击“一键生成全网引证包”，将文章转化为知乎答主版、小红书图文版与新闻通稿，点击复制并顺手分发到外部平台。
